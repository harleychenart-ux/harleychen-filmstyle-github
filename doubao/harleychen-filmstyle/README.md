# 豆包导入与使用

此目录是豆包适配版的**说明型 Skill**。它不含 API Key、不读取 macOS 钥匙串，也不承诺所有豆包版本都能执行本地 Python 脚本。

## 优先方式：豆包的 GitHub Skill 导入

如果你的豆包电脑版/办公模式的“技能”页面提供“从 GitHub 导入”“安装 GitHub 技能”或等效入口：

1. 将本仓库设为 Public，或授权豆包访问该 Private 仓库。
2. 粘贴仓库主页 URL，而不是 `SKILL.md` 的 Raw URL。
3. 选择目录 `doubao/harleychen-filmstyle`；如果界面不能选择子目录，按它的导入提示提供该目录的 GitHub 页面 URL。
4. 导入后上传一张照片，并输入“帮我生成陈下心风格”。

不同版本的入口名称与 GitHub 子目录选择能力可能不同。若页面没有 GitHub 导入入口，不要修改隐藏工作区目录；改用下方的自定义 Skill 方式。

## 通用方式：新建自定义 Skill

1. 在豆包中进入“技能”或“自定义技能”，新建一个 Skill。
2. 将 [SKILL.md](SKILL.md) 的全文粘贴进去，保存并启用。
3. 在其工具或密钥设置中确认图像编辑工具使用当前登录使用者自己的账号。
4. 仅当豆包明确提供安全变量与运行时，才创建 `HARLEYCHEN_ARK_API_KEY` 并填入使用者自己的方舟密钥；绝不能把密钥写进该 Skill 或 GitHub。

## 运行能力分级

| 豆包环境能力 | 可用路线 |
| --- | --- |
| 有原生图像编辑工具 | 直接使用当前登录账号的原生编辑工具。 |
| 有安全变量 + HTTP/Python 运行时 | 可使用方舟图像接口，但固定目标模型、端点和 `watermark: false`。 |
| 仅普通聊天或移动端 | 只能使用 Skill 作为提示词规范；不能运行本仓库的 Codex/macOS 脚本。 |

如果需要可执行的方舟 API 路线，请使用本仓库的 Codex 版，或先确认豆包工作区提供安全变量与 Python/HTTP 运行时。
