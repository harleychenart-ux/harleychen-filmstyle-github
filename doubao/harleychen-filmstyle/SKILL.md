# HarleyChen Filmstyle（豆包适配版）

将上传照片处理为自然、明亮、具有 35mm 胶片质感的电影观感。保留人物身份、五官、姿势、手部、服装图案、物件、文字、构图、裁切、透视、几何和故事；仅改变色彩、光线、颗粒和光学质感。

## 使用边界

- 触发语“帮我生成陈下心风格”是本工作流名称，不是要求模仿任何个人创作者。
- 必须有一张待编辑的图片；没有图片时请求上传。不要把它用于文生图、新场景生成、换脸、换装、背景替换或物体增删。
- 先分析画面中可见的构图、焦点、光线、曝光、高光与阴影、白平衡、主色、颗粒和材质；仅陈述可见内容。

## 使用者自己的账号

- 只使用当前已登录使用者自己的豆包/火山方舟账号。绝不请求、粘贴、展示、复用或转交任何人的 API Key。
- 如果当前账号未开通图像能力或目标模型，展示 `Doubao-Seedream-5.0-lite`、当前免费额度/价格和“安心体验”状态；只有当前使用者在本轮明确同意后，才开通该单一模型。禁止全量开通、自动开通新增模型或隐式开启付费续用。
- 优先使用豆包宿主已提供的、绑定当前登录账号的图像编辑工具。
- 只有当宿主明确支持安全密钥变量和 HTTP/Python 运行时，才能使用使用者自行配置的专属变量 `HARLEYCHEN_ARK_API_KEY` 调用方舟。密钥不得写入 Skill、GitHub 仓库、聊天内容、日志或输出文件。
- 如果宿主没有安全变量或脚本运行能力，停止在 API 路线，不要伪造已生成结果；改用该宿主自己的图像编辑工具，或请使用者改在 Codex 版运行。

## 编辑目标

目标为 Leica M6 的 35mm 观感与 Kodak VISION3 500T 色彩负片的电影层次：

- 保持自然但更有密度的色彩；仅在原图存在蓝/青或黄/金色时适度增强，保护肤色、白衣和中性表面。
- 高光柔和滚降，阴影保留纹理；轻度增强日光反差，不出现 HDR 光晕、死黑、霓虹蓝或芥末肤色。
- 高光略暖、阴影微冷中性；保留原始光向和时段。
- 加入中细、非均匀的 35mm 胶片颗粒和克制的高光晕染；不添加漏光、划痕、灰尘、重暗角、日期戳、文字、Logo 或水印。

## 执行与验收

1. 以图片编辑而非新场景生成执行，锁定主体、姿势、物件、裁切、透视、可读文字和几何。
2. 若可配置图像接口，固定使用 `https://ark.cn-beijing.volces.com/api/v3/images/generations`、模型 `doubao-seedream-5-0-260128`、`watermark: false`，并附上原图；不得改为其他端点或模型。
3. 输出前检查：没有水印或文字；人物与物件未改变；画幅比例与原图一致；高光、阴影和皮肤可信；颗粒不呈现均匀数字噪点。
4. 保存为新文件，不覆盖原图；说明实际使用的宿主工具或 API 路线与保存路径。
